# Witseek v0.4.4

## 修复

- 修复自动更新发现新版后无法进入下载阶段的问题，并在构建时校验更新配置和版本清单。
- 修复重启时旧 dsh 进程的迟到退出事件影响新进程状态的问题。
- 恢复页和目录初始化失败时，Electron 壳数据仍使用 `.dsh` 路径。
- 大文件预览改为有界读取；图片超过 8 MiB 时改用系统查看器。
- 大 Git diff 以截断预览显示；工作区内的目录链接可展开，越界链接仍受限。
- 在 dsh 注册工作区前先校验路径；丢弃切换后迟到的预览响应，并阻止工作区与安装目录重叠。
- 安装路径冲突提示显示安装目录、旁置缓存、dsh 数据目录和工作区的完整路径，方便判断冲突来源。
- 安装、更新和卸载时拒绝经过 junction 或符号链接的路径，避免程序清理误碰用户文件。
- 打包开始时清除过期的 `latest.yml`，防止构建失败后误用旧版本清单。

## 保留

- 官方 dsh 仍作为运行核心。
- 保留 Witseek Coding preset、文件预览和 Git 改动视图。
- 继续使用用户提供的鲸鱼桌面图标和免管理员权限安装方式。
