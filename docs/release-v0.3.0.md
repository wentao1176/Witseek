# Witseek v0.3.0

基于 DeepSeek 官方 Harness（`dsh`）内核的 Windows 桌面版本。

## 新增

- **右侧工作区文件预览边栏**：`Ctrl+B`（或菜单“视图 → 文件预览边栏”）开关，左缘拖拽调宽。
  - 工作区文件树，目录懒加载展开；
  - 代码 / 文本语法高亮（数十种常见语言）、Markdown 渲染、图片预览；
  - 大文件截断提示、二进制 / PDF 引导系统打开、“打开文件…”选择工作区外文件；
  - 深色主题与主界面适配；文件访问经主进程白名单 IPC 并限制在工作区内。
- **GitHub Releases 自动更新**：内置 `electron-updater`，启动后台静默检查，下载完成后引导重启；随安装包提供 `latest.yml`。
- **应用图标**：改用 Witseek 鲸鱼源图并加大圆角，同步更新 exe、窗口与安装程序图标。

## 沿用（v0.2.x）

- 内置官方 `dsh` win32-x64 运行时与独立 Windows Node，无需自备环境；
- 模型 / 插件 / 工具 / 会话全部来自官方 Harness（一切皆插件）；
- API Key 在“设置 → 模型”中配置并持久化；
- 免 UAC 的 per-user NSIS 安装程序，带快捷方式与卸载器。

## 安装

下载 `Witseek-Setup-0.3.0.exe` 双击安装（未做代码签名，首次 SmartScreen 可能提示，选择“仍要运行”）。
