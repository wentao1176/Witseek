## 五、复现方式

```bash
# 服务器上
cd /media/hnu/hnu2021/dengxin/xuanwentao/Witseek

bash scripts/scaffold_p2_kernel.sh   # 生成 protocol / provider-deepseek / tools
bash scripts/scaffold_p2_core.sh     # 生成 harness-core + vitest 配置 + 离线演示
bash scripts/scaffold_p2_tests.sh    # 生成根 package.json + 全部单测

pnpm install --no-frozen-lockfile
pnpm typecheck
bash scripts/test.sh
pnpm demo:kernel
```

> `--no-frozen-lockfile` 是必需的：环境里 `CI=1` 会让 pnpm 默认走冻结锁文件，
> 任何 `package.json` 变更都会让 `pnpm install` 直接失败。
